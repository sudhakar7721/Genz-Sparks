# EduNexa V14 — Student Timetable 5 × 6 Update

- Student Class Timetable now renders exactly **5 days × 6 periods**: Monday–Friday and Period 1–6.
- Subject name and faculty name remain displayed inside each timetable cell.
- Period time ranges remain in the column headers.
- Existing backend/API/database process is unchanged.
- Existing Faculty, HOD, Management, login, attendance, leave, tests, assignments, notifications and other modules are preserved.
- Saturday and Period 7 are not displayed in the Student timetable matrix, even if older database records contain them.
