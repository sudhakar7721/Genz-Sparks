# EduNexa API Map

| Frontend feature | API |
|---|---|
| Login | POST `/api/auth/login` |
| Signup | POST `/api/auth/signup` |
| Current user | GET `/api/me` |
| Student profile | GET `/api/students/me` |
| Student list | GET `/api/students` |
| Faculty profile | GET `/api/faculty/me` |
| Faculty list | GET `/api/faculty` |
| Mentor list | GET `/api/faculty/mentors` |
| Adviser list | GET `/api/faculty/advisers` |
| Marks | GET/POST/PUT `/api/marks/...` |
| Attendance | GET/POST `/api/attendance/...` |
| Fees | GET/POST/PUT `/api/fees/...` |
| Tests | GET/POST `/api/tests` |
| Assignments | GET/POST `/api/assignments` |
| Submissions | POST/GET `/api/submissions...` |
| Leave | POST `/api/leaves`, GET `/api/leaves/my`, GET `/api/leaves/pending`, PUT review |
| Skills/Mentor | GET/POST/PUT `/api/skills/...` |
| Feedback | POST/GET/PUT `/api/feedback...` |
| Placements | GET/POST `/api/placements` |
| Notifications | GET/POST/PUT `/api/notifications...` |
| Management dashboard | GET `/api/management/dashboard` |
| Management departments | GET `/api/management/departments` |
