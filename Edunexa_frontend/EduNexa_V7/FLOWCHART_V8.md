# EduNexa V8 – Staff Login Flow

```text
EduNexa Login
│
├── Student Login
│   └── Existing Student Dashboard & features
│
├── 👨‍🏫 Staff Login (single section)
│   │
│   ├── 👨‍🏫 Faculty Login
│   │   └── Existing Faculty Dashboard, timetable, tests,
│   │       assignments, attendance, marks, adviser, mentor,
│   │       feedback, notifications and other features
│   │
│   └── 🏛️ HOD Login
│       └── Existing HOD Dashboard, faculty/student records,
│           class details, timetables, attendance, feedback,
│           mark-change approvals and other HOD features
│
└── Management Login
    └── Existing Management Dashboard and all modules
```

**Change in V8:** Faculty and HOD are presented as two login types inside one Staff Login section. Existing modules and permissions are preserved.
