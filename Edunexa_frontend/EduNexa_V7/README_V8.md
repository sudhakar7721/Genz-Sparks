# EduNexa V8

## Staff Login
Faculty and HOD now share one **Staff Login** section. Select Staff, then choose either **Faculty Login** or **HOD Login**.

### Demo accounts
- Faculty: faculty@edunexa.com / 123456
- HOD: hod@edunexa.com / 123456
- Student: alexa@example.com / 123456
- Management: admin@edunexa.com / 123456

All existing EduNexa features are retained. The change only reorganizes the login choice; the selected role still opens its own dashboard and permissions.
