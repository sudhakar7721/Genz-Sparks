# Department-Wise Access Rules

| Role | Visibility | Actions |
|---|---|---|
| Student | Own record and own class/department academic content | Own submissions, leave, profile and personal academic actions |
| Faculty | Students belonging to the faculty's department | Attendance, marks, leaves, adviser/mentor functions and department assessments |
| HOD | Students and faculty belonging to the HOD's department | Department student/faculty oversight, mark approvals and HOD workflows |
| Management | All departments | College-wide management, reports, fees, marks and placement views |

## Class Adviser Privacy Layer
- Student personal/profile details are visible only to the assigned Class Adviser (and Management).
- Student leave requests, reasons and review controls are visible only to the assigned Class Adviser (and Management).
- Non-adviser Faculty retain same-department academic visibility but cannot open private student profile or leave details.
- HOD retains same-department academic visibility but cannot open private student profile or leave details.
- Class Adviser access is limited to `classesHandled` where class metadata is available.
